## 📋 À FAIRE MAINTENANT (5-10 min)

### 1. ⚠️ IMPORTANT : Ajouter vos 5 icônes PNG

**Fichiers requis :**
```
images/icons/
├── learning.png      (Apprentissage continu)
├── discipline.png    (Discipline)
├── audacity.png      (Audace)
├── sharing.png       (Partage de connaissances)
└── impact.png        (Impact positif)
```

**Où trouver des icônes gratuites ?**
- [Flaticon](https://www.flaticon.com) - Cherchez "learning icon", etc.
- [Icons8](https://icons8.com) - Style flat moderne
- [Iconscout](https://iconscout.com/free-icons)

**Spécifications :**
- Format : PNG avec fond transparent
- Taille : 80x80px minimum (ou plus, sera redimensionné auto)
- Style : Cohérent pour toutes les icônes
- Couleur : Vert (#00866A), noir ou multicolore

**Instructions détaillées :**  
👉 Voir `images/icons/README.md`

### 2. ✅ Tester le site (2 min)

1. Double-cliquez sur `index.html`
2. Cliquez sur chaque lien du menu
3. Testez les "Quick Links" sur la page d'accueil
4. Vérifiez que tout s'affiche correctement
5. Testez sur mobile (réduisez la fenêtre)

### 3. ✅ Personnaliser vos infos

Dans `data.js`, ajoutez :
```javascript
personal: {
    email: "votre-email@example.com", // ⬅️ Ajoutez votre email
},
social: {
    linkedin: "https://linkedin.com/in/votre-profil", // ⬅️ Si vous avez
}
```

### 4. 🚀 Mettre en ligne (15 min)

**Option recommandée : GitHub Pages (gratuit)**

1. Créez un compte sur [GitHub](https://github.com)
2. Créez un repository : `votre-username.github.io`
3. Uploadez tous les fichiers
4. Settings > Pages > Deploy from branch `main`
5. Votre site sera à : `https://votre-username.github.io`

**Alternatives :**
- [Netlify](https://netlify.com) - Glissez-déposez le dossier
- [Vercel](https://vercel.com) - Import et déploiement auto
