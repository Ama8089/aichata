# Icônes de Valeurs

Ce dossier contient les icônes PNG pour la section "Mes valeurs".

## Icônes requises (80x80px recommandé)

1. **learning.png** - Apprentissage continu
   - Suggestion : Icône de livre, cerveau, ampoule ou graduation

2. **discipline.png** - Discipline
   - Suggestion : Icône de cible, médaille, checklist ou bras musclé

3. **audacity.png** - Audace
   - Suggestion : Icône de fusée, montagne, étoile ou escalier ascendant

4. **sharing.png** - Partage de connaissances
   - Suggestion : Icône de personnes, mains qui se serrent, réseau ou discours

5. **impact.png** - Impact positif
   - Suggestion : Icône d'étincelles, cœur, main tendue ou graphique croissant

## Où trouver des icônes gratuites ?

### Sites recommandés :
- **Flaticon** : https://www.flaticon.com (gratuit avec attribution)
- **Icons8** : https://icons8.com (gratuit avec attribution)
- **Iconscout** : https://iconscout.com/free-icons
- **Noun Project** : https://thenounproject.com
- **Freepik** : https://www.freepik.com/icons

### Conseils :
- Format : PNG avec fond transparent
- Taille : 80x80px minimum (ou plus grand, sera redimensionné automatiquement)
- Style : Choisissez un style cohérent pour toutes les icônes (flat, line art, etc.)
- Couleur : De préférence en vert (#00866A) ou noir, ou multicolore selon votre préférence

## Exemple de recherche :
- "learning icon png"
- "discipline icon flat"
- "rocket icon transparent"
- "handshake icon outline"
- "sparkle icon png"

## Installation :
1. Téléchargez les 5 icônes
2. Renommez-les exactement comme ci-dessus
3. Placez-les dans ce dossier `images/icons/`
4. Actualisez votre site

## Temporaire :
En attendant vos icônes personnalisées, vous pouvez utiliser des icônes de placeholder ou laisser les emojis actuels.
