## 🎨 Avantages du multi-pages

### ✅ Meilleur pour le SEO
- Chaque page a son propre titre et meta description
- URLs plus claires et partageables
- Meilleur indexation par Google

### ✅ Meilleure navigation
- Liens partageables vers des sections spécifiques
- Navigation browser (précédent/suivant) fonctionne
- Bookmarks possibles sur chaque page

### ✅ Plus professionnel
- Chargement plus rapide (seulement le contenu nécessaire)
- URLs propres : `/expertise.html`, `/projets.html`, etc.
- Facilite l'ajout de nouvelles pages

## 📋 À FAIRE MAINTENANT

### 1. Ajouter vos icônes de valeurs (5 min)

**Option A : Télécharger des icônes gratuites**

Sites recommandés :
- [Flaticon](https://www.flaticon.com) - Cherchez "learning icon", "discipline icon", etc.
- [Icons8](https://icons8.com) - Style flat moderne
- [Iconscout](https://iconscout.com/free-icons) - Large sélection

**Étapes :**
1. Téléchargez 5 icônes PNG (fond transparent, ~80x80px)
2. Renommez-les :
   - `learning.png` (Apprentissage)
   - `discipline.png` (Discipline)
   - `audacity.png` (Audace)
   - `sharing.png` (Partage)
   - `impact.png` (Impact positif)
3. Placez-les dans `images/icons/`

**Option B : Garder les emojis temporairement**

Si vous n'avez pas encore les icônes, vous pouvez remettre les emojis en attendant.

### 2. Tester la navigation (2 min)

1. Ouvrez `index.html` dans votre navigateur
2. Cliquez sur chaque lien du menu
3. Vérifiez que toutes les pages se chargent correctement
4. Testez sur mobile (responsive)

### 3. Personnaliser les contenus

Dans `data.js` :
- ✅ Email
- ✅ Liens sociaux (déjà faits)
- 📝 Articles de blog
- 📸 Photos de conférences

## 🎨 Personnalisation future

### Ajouter une nouvelle page ?

1. Copiez une page existante (ex: `a-propos.html`)
2. Renommez-la (ex: `services.html`)
3. Modifiez le contenu
4. Ajoutez le lien dans le menu de **toutes les pages**
5. Ajoutez le lien dans le footer

### Changer les couleurs des icônes ?

Dans Photoshop, Gimp ou un éditeur en ligne, changez la couleur des icônes PNG avant de les ajouter.
